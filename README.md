# 🚀LocationTraking

## 🤖 Projede AI Kullanımı

Bu projede geliştirme hızını ve kod kalitesini artırmak için yapay zeka araçlarından aşağıdaki alanlarda faydalanılmıştır:

* **Cursor IDE:** Proje mimarisinin kurulması, katmanlı yapı (`.cursorrules` ile) ve hızlı refactoring süreçlerinde kullanıldı.
* **Google AI Studio:** Model denemeleri yapılması, prompt'ların test edilmesi ve arayüz (UI) bileşenlerinin prototiplenmesinde tercih edildi.
* **Google Gemini:** Karmaşık mantıkların/algoritmaların çözümü, edge-case senaryolarının belirlenmesi ve dokümantasyon desteği için kullanıldı.
